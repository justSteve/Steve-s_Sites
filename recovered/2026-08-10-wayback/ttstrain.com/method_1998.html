Total Training Solutions utilizes a systematic approach to project management. Our product development process is comprised of an ordered series of predefined and predetermined steps used to take a project from inception to completion. Total Training Solutions will work with your institution to ensure that all of these steps are completed.

Our instructional design methodology includes these steps:

1. Analyze Needs 2. Draft Mission Statement 3. Create Audience Profile 4. Write Objectives 5. Analyze and Outline Content 6. Layout Course Map 7. Define Treatment 8. Select Learner Activities 9. Storyboard Course 10. Produce Media 11. Author Course 12. Evaluate Course
Phase One: Project Analysis & Design
Phase One begins with a needs analysis session. At this time, the training project's goals are determined.

Phase One Outcome: A Detailed Project Plan
The project plan and schedule will outline the major milestones of the project, with the corresponding completion dates. It will serve as the main document the Project Manager will use to ensure the project meets the specified deadline and goals.

Phase Two: Script/Storyboard Development
Phase Two consists of script and storyboard development. The storyboard consists of actual on-screen text, a narration script, description of graphics, screen layout and course flow. To write the storyboard, the instructional designer, the subject matter expert, and the scriptwriter will review the existing course material, reorganize and rewrite it for optimum instructional effectiveness in a computer-based training environment. In addition, original script content will be developed. Test questions will also be created at this point.

Phase Two Outcome: Final Script/Storyboard
The storyboard is the final course reference document. It normally goes through one or two revisions prior to sign-off.

Phase Three: Pre-production
Phase Three is when the program begins to be created on the computer. All initial design elements are being developed and incorporated into the program. The graphic artist works with the instructional designer and the programmer to develop the "look and feel" of the training program.

Phase Three Outcome:
The project manager should see a preview of the completed or partially completed program screens so that they will be able to sign off on the graphical design of the program.

Phase Four: Production
The production stage includes the creation of all course components, including final art work, animation, video and audio production (when used), navigation, system branching, user testing/evaluation, and application development for the course. A database will be created for test questions and user input data will be tracked and compiled for analysis.

Phase Four Outcome: Sample Graphics and Authored Courseware
During the production phase, the project manager should see sample graphics and functioning pieces of the authored courseware. The client will approve the developed elements of the program to date, as well as the courseware's functionality, prior to Phase Five.

Phase Five: Post-production
Phase Five is when the different media elements (e.g., graphics, video, audio, etc.) are integrated into the program. The programming/authoring of the project is completed. At this point, the program will be complete except for the revisions made after beta-testing is finished.

Phase Five Outcome: The Program On Disk
The project manager should receive a fully functioning program on disk which allows them to beta-test the program in their training environment and with their audience. The project should be evaluated both in terms of its overall educational value and effectiveness and, in addition, its playback performance on the client's computers.

Phase Six: Testing, Validation and Delivery
At this point, the actual on-screen text will be given a final proof reading for grammar, consistency, spelling and punctuation. Then the project team will step thorough the program, screen by screen, to compare it with the storyboards for content and functionality. Individuals with no prior knowledge of the subject matter will test the program as well.

Phase Six Outcome: Final Courseware
After testing and validation, the client will review for the second, and final time, and provide suggestions for corrections or changes, if any. Any functionality changes from the original script and storyboard will affect budget and timeline.

Average Development Time
Programs vary depending on the complexity and level of programming. Average development time for one hour of seat time may range from 90 - 150 hours. This time length can be reduced by using existing templates or models.
